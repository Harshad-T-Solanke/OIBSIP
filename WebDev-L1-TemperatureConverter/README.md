# Temperature Converter

A professional, responsive temperature conversion web application built for the **Oasis Infobyte Web Development and Designing Internship — Level 1 Task 3**.

TempConvert allows users to convert temperatures between **Celsius, Fahrenheit and Kelvin** with accurate calculations, validation, unit swapping, keyboard support and a clean responsive interface.

---

## Features

- Celsius conversion
- Fahrenheit conversion
- Kelvin conversion
- Conversion between all six unit combinations
- Input validation
- Decimal value support
- Maximum two decimal places
- Automatic removal of unnecessary trailing zeros
- Kelvin validation below 0 K
- Swap units functionality
- Reset functionality
- Dynamic result display
- Enter-key conversion
- Common conversion reference cards
- How-it-works section
- Responsive design
- Mobile-friendly UI
- Semantic HTML5
- Accessible labels
- Keyboard-friendly controls
- Separate HTML, CSS and JavaScript files
- Professional developer-style UI

---

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript

No frameworks or external libraries are used.
