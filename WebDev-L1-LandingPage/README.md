# NexaTech – Modern Technology Landing Page

A professional and responsive landing page created for the **Oasis Infobyte Web Development and Designing Internship – Level 1, Task 1: Landing Page**.

The project presents **NexaTech**, a fictional modern technology brand focused on building fast, secure and easy-to-use digital solutions.

---

## 🚀 Project Overview

NexaTech is a modern technology landing page designed to demonstrate fundamental front-end web development skills using:

* HTML5
* CSS3
* CSS Flexbox
* CSS Grid
* Responsive Design
* Semantic HTML
* CSS Hover Effects
* Modern UI Design

No JavaScript is used in this project.

## ✨ Features

### 1. Sticky Navigation Bar

The website includes a sticky navigation bar containing:

* NexaTech logo
* Home
* Features
* About
* Contact
* Get Started button

Navigation links include hover effects.

---

### 2. Hero Section

The hero section contains:

* Main headline:
  **"Build Smarter. Grow Faster."**
* Professional product description
* Get Started CTA
* Explore Features button
* Technology-inspired CSS illustration
* Business statistics

The hero section uses a two-column layout on desktop and automatically becomes a single-column layout on mobile.

Each card includes a description and hover effect.

### 5. Call-To-Action Section

The website uses a modern technology-inspired visual style.

* Primary: Purple

* Accent: Soft Purple

The design also uses:

* Rounded cards
* Subtle shadows
* Consistent spacing
* Hover effects
* Modern typography
* Gradient backgrounds

---

## 📱 Responsive Design

The website is responsive for:

* Desktop
* Laptop
* Tablet
* Mobile

CSS media queries are used to adapt the layout.

On smaller screens:

* Navigation adapts to available width
* Hero content becomes vertically stacked
* Feature cards become single-column
* About section becomes single-column
* Footer content becomes vertically stacked
* Buttons become full width
